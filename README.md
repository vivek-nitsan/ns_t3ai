# T3AI Free (AI Foundation)

Free TER/GitHub edition of T3AI. Powered by **AI Foundation** (`ns_t3af`). Includes SEO **page-title** suggestions and **RTE** AI generate/rewrite (~10–15% of Pro).

## Setup

1. Install `ns_t3af` + `ns_license` + this extension (`ns_t3ai` 15.0.0+)
2. In **AI Foundation**, add and test a provider
3. Optionally set `defaultProviderForSeo` / `defaultProviderForContent` (`default` = AF global)
4. Use page-title SEO + RTE AI

**Breaking in 15.0.0:** OpenAI API key / model inside T3AI settings are removed. Configure providers in AI Foundation.
